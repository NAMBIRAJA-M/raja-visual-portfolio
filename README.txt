RAJA VISUAL — CINEMATIC PORTFOLIO WEBSITE

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the raja-visual-portfolio folder.
3. Double-click index.html to open it in your browser.

The hero portrait is included locally in assets/hero.webp.
Project-card photos are loaded from Unsplash, so an internet connection is needed for those images.

CUSTOMISE BEFORE PUBLISHING
- Replace the five sample project cards in index.html with your real project names, thumbnails, descriptions, and video links.
- Update the contact email and Instagram URL if needed.
- Publish the extracted folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages.

The contact form opens a prefilled email draft in the visitor's mail app; it does not submit to a server.
